# Borradores legales de Tinotify

**Son borradores técnicos, no asesoría legal.** Describen lo que el sistema hace hoy. Antes de invitar a otras personas, deben revisarse con un abogado (Ley 1581 de 2012, Decreto 1377 de 2013, transferencia internacional de datos y los términos de uso de SIGAC).

Marcadores a completar: `[RESPONSABLE]`, `[CONTACTO]`, `[FECHA]`, `[PLAZO]`, `[JURISDICCIÓN]`. No poner correos ni teléfonos personales en el repositorio (es público): publicar los textos finales en una URL aparte.

- `politica-tratamiento-datos.md`: política de tratamiento y aviso de privacidad.
- `terminos-de-uso.md`: condiciones del servicio.
- `consentimiento-en-app.md`: textos de la pantalla de consentimiento.

Regla: si el sistema cambia lo que guarda, estos textos cambian en el mismo PR y la app vuelve a pedir el consentimiento (versión del texto).
